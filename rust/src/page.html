设置

传感器数据支持 MSI Afterburner 与 HWiNFO 两个来源，游戏帧率来自 RTSS。
开关会写入 Windows 启动项（HKCU\...\Run），关掉即移除。
AfterburnerWebMonitor 开机自启
开机后自动启动本监控服务
—
MSI Afterburner 开机自启
不启动 Afterburner 就没有任何数据
传感器数据（温度 / 占用 / 频率）都来自它
—
RTSS 开机自启
不启动 RTSS 就无法读取帧数
RTSS 负责统计游戏帧率（Afterburner 会带起它）
—
HWiNFO 开机自启
不启动 HWiNFO 就看不到它的数据
它需要管理员权限，开机时会弹一次 UAC（不点则不启动）
